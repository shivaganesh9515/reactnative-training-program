# Assessment Template (Trainer Role)
> Use this to assess junior developers at each milestone.

---

## How to Use
1. Schedule 30-min assessment at end of each month
2. Developer presents their project
3. Ask questions from the assessment
4. Score each section
5. Provide written feedback
6. Agree on next month's goals

---

## Month 1 Assessment: Core React Native

### Project Presentation (10 min)
- [ ] Developer demos their Note-taking app
- [ ] Can navigate between all screens
- [ ] Dark mode toggle works
- [ ] Notes persist after restart

### Technical Questions (15 min)

**Fundamentals**
- [ ] Explain the difference between `<View>` and `<div>`
- [ ] Why can't you use CSS classes in React Native?
- [ ] What's the difference between `onChange` and `onChangeText`?
- [ ] How do you handle text overflow?

**Navigation**
- [ ] Explain stack vs tab navigation
- [ ] How do you pass params between screens?
- [ ] What file does Expo Router use for layouts?
- [ ] How do you handle deep links?

**Lists & Forms**
- [ ] Why use FlatList instead of ScrollView for long lists?
- [ ] What is `getItemLayout` for?
- [ ] How do you handle keyboard on mobile?
- [ ] What's the best way to validate forms?

**Styling**
- [ ] How do you implement dark mode?
- [ ] What's `Platform.select()` for?
- [ ] How do you handle responsive design without media queries?

### Code Review (5 min)
- [ ] Code is organized logically
- [ ] No obvious anti-patterns
- [ ] TypeScript types are correct
- [ ] Error states are handled
