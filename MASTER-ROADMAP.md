# React Native Training Program
## 4-Month Junior Developer Roadmap

> **Audience:** Junior developers joining the team
> **Prerequisites:** JavaScript, React, Next.js, TypeScript basics
> **Commitment:** 3-4 hours/day, 5 days/week
> **Outcome:** Job-ready React Native developers with 4 portfolio projects

---

## Program Structure

```
MONTH 1          MONTH 2          MONTH 3          MONTH 4
Core RN          Real Features    Advanced         Production
─────────────────────────────────────────────────────────────
Week 01-04       Week 05-08       Week 09-12       Week 13-16
Fundamentals     Data & APIs      Polish & Test    Ship & Deploy
```

## Milestones

| Month | Milestone | Deliverable | Verified By |
|-------|-----------|-------------|-------------|
| 1 | Build basic RN apps | Note-taking app | Trainer |
| 2 | Connect to APIs + Auth | Movie tracker app | Tech Lead |
| 3 | Production patterns | Chat UI clone | Code Review |
| 4 | Deploy to stores | Full app on App Store/Play Store | Team Lead |

## Weekly Schedule (3-4 hrs/day)

| Day | Activity | Time |
|-----|----------|------|
| Monday | New concept + official docs | 3 hrs |
| Tuesday | Code along / tutorial | 3 hrs |
| Wednesday | Build your own feature | 4 hrs |
| Thursday | Build your own feature | 4 hrs |
| Friday | Debug, review, assessment | 3 hrs |

## Files Per Week

Each week folder contains:
- `TASK.md` — What to do (copy-paste ready)
- `CONCEPTS.md` — Theory and references
- `EXERCISE.md` — Hands-on practice
- `VERIFY.md` — Self-check before marking done

## Grading

| Grade | Criteria |
|-------|----------|
| PASS | All tasks complete, app runs, verification passed |
| PASS w/ notes | Tasks complete, minor issues noted in review |
| RETRY | Incomplete or critical issues found |

## Escalation Path

1. Stuck 30+ min → Check CONCEPTS.md and docs
2. Still stuck → Ask teammate (pair programming)
3. Still stuck → Ask trainer in weekly 1-on-1
4. Blocked on environment → Ask tech lead immediately

---

## Program Rules

1. **No tutorials without building.** Every concept must be applied in code.
2. **Verification is mandatory.** Never claim done without running verification.
3. **Git every Friday.** Push your week's work to your branch.
4. **Ask early.** Being stuck is fine. Being stuck for days is not.
5. **Code review is learning.** Give and receive feedback weekly.

## Month-by-Month Overview

### Month 1: Core React Native (Week 01-04)
**Goal:** Think in mobile, not web.

- Week 01: React Native fundamentals (components, styling, Flexbox)
- Week 02: Navigation (Stack, Tabs, dynamic routes)
- Week 03: Lists, forms, user input
- Week 04: Styling, theming, dark mode

**Project:** Note-taking app (CRUD, local storage, navigation)

### Month 2: Real Features (Week 05-08)
**Goal:** Build apps that talk to the world.

- Week 05: State management (Context, Zustand, TanStack Query)
- Week 06: API integration, error handling, offline detection
- Week 07: Native features (camera, location, notifications)
- Week 08: Storage (AsyncStorage, SecureStore, MMKV)

**Project:** Movie tracker app (API, auth, favorites, local storage)

### Month 3: Advanced Patterns (Week 09-12)
**Goal:** Ship production-quality code.

- Week 09: Animations (LayoutAnimation, Reanimated basics)
- Week 10: Performance (memo, FlatList optimization, Flipper)
- Week 11: Authentication (OAuth, JWT, secure storage)
- Week 12: Testing (Jest, RNTL, Maestro E2E)

**Project:** Chat UI clone (animations, performance, tests)

### Month 4: Production & Deployment (Week 13-16)
**Goal:** Ship to real users.

- Week 13: Architecture (feature folders, custom hooks, error boundaries)
- Week 14: Platform-specific code (iOS vs Android differences)
- Week 15: Build and deploy (EAS Build, app store submission)
- Week 16: CI/CD, monitoring, beta testing, launch

**Project:** Deploy your best project to App Store + Play Store
